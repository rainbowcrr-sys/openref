本页说明 OpenRef（`https://openref.de5.net`）内容的著作权归属与使用规则。自 2026-10-28 起生效。

## 一、著作权归属

| 内容类型 | 著作权人 |
|---|---|
| 运营者原创条目 | OpenRef 运营者 |
| 投稿条目 | 原投稿人（署名见文末） |
| 站点代码与模板 | 仓库开源协议（MIT） |

投稿内容的著作权不因发布而转移，详见[投稿协议](/contribute/agreement/)。

## 二、转载政策（允许转载，但有三个条件）

OpenRef **允许转载**。但每一次转载都必须同时满足以下三条，缺一不可：

**① 必须署名原作者**

转载时须清晰标注原作者署名。署名见条目文末；匿名投稿的写"匿名投稿人"。

**② 必须包含原文链接**

须在转载页面显著位置放置指向原文的**可点击链接**，例如：

```
本文转载自 OpenRef 技术参考
作者：XXX
原文：https://openref.de5.net/docs/.../
```

仅写"来源网络"、仅写站点名而不给链接，均视为不满足条件。

**③ 必须事先申请并获得同意**

转载前请发邮件申请，收到明确同意后方可转载。

```
收件人：contact@openref.de5.net
主题：[转载申请] 打算转载的条目标题
正文：
  - 打算转载的条目原文链接
  - 转载平台（公众号 / 博客 / 论坛 / 其他）
  - 是否商业用途
  - 是否会对内容做删改
```

**审核周期：3 个工作日内回复**（节假日顺延）。未收到回复前请勿转载。

:::warn 未获同意的转载视为侵权
未满足以上三条中任意一条的转载，本站保留要求删除、公开更正、追究责任的权利。
:::

## 三、许可协议

站内容在获得转载许可后，适用 **CC BY-NC-SA 4.0**：

```
署名（Attribution）        — 必须注明原作者
非商业性使用（NonCommercial）— 不得用于商业目的
相同方式共享（ShareAlike）   — 衍生作品须采用相同协议
```

**代码示例**遵循各项目自身的开源协议（MIT / Apache-2.0 等），以代码注释或文中标注为准。

**站点构建代码**采用 MIT 协议，见仓库 LICENSE。

## 四、除了转载之外的允许与禁止

**允许**（无需申请）：

- 链接并分享本站条目页面
- 引用代码片段用于学习、教学、开发（注明出处）
- 将条目纳入搜索引擎与 AI 检索索引
- 打印本页面供个人学习

**禁止**：

- 去除署名或伪称原创
- 未获同意的转载
- 用于商业出版、付费课程等营利场景
- 批量抓取后整站镜像
- 将内容用于训练商业闭源模型（非商业个人学习除外）

## 四、引用规范

引用本站条目时，建议采用以下格式：

```
作者名.《条目标题》. OpenRef 技术参考. 发布年份.
URL: https://openref.de5.net/docs/.../
许可：CC BY-NC-SA 4.0
```

## 六、侵权投诉

如果你认为本站内容侵犯了你的合法权益，发邮件至 `contact@openref.de5.net`，请包含：

- 你的身份证明与联系方式
- 被侵权内容的准确地址
- 权利归属证明
- 要求（删除 / 修改 / 补充署名）

收到有效投诉后，本站会在合理时间内处理并回复。

## 七、内容撤回

已发布内容如需撤回，适用[投稿协议](/contribute/agreement/)第六条的缓存限制：

搜索引擎快照、第三方转载、AI 索引中的内容**不在本站控制范围内**，无法保证同步删除。
