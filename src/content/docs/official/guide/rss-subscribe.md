RSS 是一种很老的协议，但到今天仍然是「不打扰地看更新」最好的方式：没有算法推荐、没有推送权限、没有账号绑定。你把一个地址交给阅读器，之后有新文章它自己去取。

OpenRef 的订阅分成五层，粒度从粗到细：

- **全站** —— 所有文章，最常用
- **大类** —— 只收某个主题，例如「云原生与基础设施」
- **子类** —— 更细一层，例如 Cloudflare、SEO
- **标签** —— 跨分类按关键词聚合，例如 `#D1`
- **单篇** —— 只订这一篇，文章有修改时你会收到更新

「自选大类或子类」不是让你勾选生成一份专属源，而是把现成的地址列出来，你自己复制想要的那几条。静态站不会拼装个人化 feed，这样反而更稳：地址是死的，永远有效。

## 网页：Feedly / Inoreader

适合在电脑浏览器里看，换设备自动同步。

1. 打开 feedly.com 或 inoreader.com，注册并登录
2. 找到 **Add Content / 添加订阅**（Feedly 是左侧 `+ Follow`，Inoreader 是左上角 `+`）
3. 粘贴下面清单里的地址，点 **Follow / 订阅**

想一次导入全部五层，用 OPML：阅读器里找 **Import OPML**，上传 `opml.xml`，所有地址会按「全站 / 大类 / 子类 / 标签 / 单篇」分好组。

## 手机：NetNewsWire / Inoreader

适合通勤时刷。NetNewsWire 是 iOS/macOS 上的免费开源阅读器；Inoreader 有 iOS 和安卓 App。

1. 在 App Store / 应用商店装好 App，登录（NetNewsWire 可以不登录直接用）
2. 点 **+** → **Add Feed / 添加订阅**
3. 粘贴地址 → 确认

iOS 上也可以直接在 Safari 里点页面上的订阅图标，系统会提示用哪个阅读器打开。安卓同理，取决于你装了哪些支持 RSS 的 App。

## 桌面：RSS Guard

Windows / macOS / Linux 都能装，纯本地，不依赖任何账号。

1. 打开 RSS Guard，菜单 **Feeds → Add new feed**
2. 粘贴地址，起个名字，选好归到哪个文件夹
3. 点 **OK**，之后按 F5 或设定间隔自动拉取

桌面客户端同样支持 **Import OPML**：Feeds → Import/Export → Import feeds from OPML 2.0。

## 自建：FreshRSS

想把订阅完全握在自己手里，用 FreshRSS（PHP，可跑在 NAS / 小主机上）。

1. 按官方文档部署好 FreshRSS 并登录
2. 左侧 **+ 添加信息源**，粘贴地址
3. 保存后放进对应分类目录，配置好自动更新周期

导入 OPML：设置 → 导入/导出 → 选择 `opml.xml` 上传。之后手机可以用支持 Fever / GReader API 的 App 连自己的服务器。

## 几个常见问题

**地址能改吗？** 不能随便改。文章和分类的地址是固定死的，改名会让旧订阅失效，所以文件名和路径一律用英文小写，页面上的中文只是显示名。

**订阅后为什么没立刻看到新文章？** 阅读器按自己的周期拉取，通常几分钟到一小时。想马上看，手动刷新一下。

**单篇订阅有什么用？** 比如你只关心 D1 那篇的额度说明，订阅它之后，文章一旦修订，阅读器就会把更新推给你，不用整站都订。

**会不会重复推送？** 不会。同一篇文章在五层 feed 里的唯一标识都是它的文章链接，同时订多份时阅读器会自动去重。
